 # TaxiPredeal Website

🔗 Live: https://taxipredeal.com

## Description
TaxiPredeal is a business website developed from scratch to support a local transport service in Predeal, Romania. The website has been continuously maintained and improved since 2016.

## Key Achievement
The website consistently ranks in **Top 1–2 positions on Google** for relevant local search queries in a highly competitive and limited tourism market.
